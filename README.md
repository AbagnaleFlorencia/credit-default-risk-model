# Predicción de Riesgo de Default Crediticio

> Proyecto en construcción — este README se irá completando a medida que avance el trabajo.

## Qué es esto

Un modelo de clasificación para predecir si un solicitante de un préstamo de home equity
va a incurrir en default (incumplimiento de pago), usando el dataset público **HMEQ**
(Home Equity Loan Default).

Manejo explícito de valores faltantes, modelos adicionales y
explicabilidad con SHAP.
